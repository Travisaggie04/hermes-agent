# Long-Form Proof Plan - 2026-06-12

This is a planning-only proof plan. It does not approve rendering a full episode,
posting, scheduling, account mutation, paid tool purchases, hidden workers,
timers, or live platform actions.

## Decision

Do not restart full long-form production yet.

Run one 10-15 second proof that answers whether the adult animated Signal Room
direction can become a repeatable long-form production method.

The proof should test the smallest hard question:

Can the system combine a reusable adult character moment, deterministic
mechanism animation, narration, captions, and final assembly into a polished
clip that feels good enough to scale?

## Why This Path

The adult animated Signal Room path has the strongest continuity with previous
work:

- Moho character fee-machine proof already showed transparent character frames
  can composite over deterministic mechanism animation.
- Adult character rig selection already identified CC0 adult character
  candidates.
- Pacing/realism and rural-air-service proofs already tested narration, audio,
  and longer-form assembly improvements.

The weak points are also clear:

- no final brand art,
- no proven facial acting,
- no proven lip sync,
- no reusable mouth switches,
- no stable episode template,
- no long-form quality lock or queue ledger.

That makes a small proof the right next move.

## Proof Requirements

Duration:

- 10-15 seconds.

Content:

- one sentence of narration,
- one mechanism or process being explained,
- one adult character reaction or gesture,
- one visual payoff.

Required artifacts:

- source prompt/brief,
- asset list,
- tool list,
- render steps,
- final clip path,
- screenshots or frame stills,
- quality review,
- failure notes,
- "scale/no-scale" decision.

Suggested proof concept:

> A character watches a simple fee machine turn one small fee into five hidden
> downstream costs.

This concept fits the existing fee-machine proof history and tests whether
character acting plus mechanism animation can carry a business explainer.

## Toolchain

Primary deterministic path:

- Moho for character pose/rig/mouth/transparent frames,
- Inkscape for clean vector assets,
- Cavalry or scriptable animation for the mechanism,
- DaVinci Resolve for edit, audio, captions, and final assembly,
- local scripts for evidence packet and quality checks.

Optional generative path:

- generative video services may be used only as reference or controlled proof
  input,
- do not make a paid purchase without approval,
- do not make generative video the source of truth until rights, cost,
  repeatability, and API reliability are reviewed.

## Pass Criteria

The proof passes only if:

- the clip has a clear hook within 2 seconds,
- the character and mechanism appear visually coherent,
- narration timing feels intentional,
- text/captions are legible,
- audio is clean,
- render steps are reproducible,
- the proof can be turned into a reusable template,
- reviewer can identify the exact next production bottleneck.

## Fail Criteria

The proof fails if:

- character animation consumes too much manual work,
- style is inconsistent across frames,
- lip sync or mouth switching is not tractable,
- mechanism animation looks cheap or confusing,
- narration feels generic,
- final assembly requires too much manual patching,
- source files cannot be reproduced.

## Fallback Plan

If adult character work blocks, switch to a faceless mechanism explainer proof:

- no character,
- same fee-machine concept,
- motion graphics and narration only,
- Inkscape + Cavalry/scriptable animation + DaVinci,
- same 10-15 second duration,
- same quality review packet.

This fallback tests whether a deterministic faceless workflow can reach a
higher quality bar faster than character animation.

## Long-Form System Gates

Before any full episode:

- long-form quality lock exists,
- metadata contract exists,
- queue ledger exists,
- source/evidence packet exists,
- title/thumbnail review exists,
- local render path is repeatable,
- safety policy for factual claims exists,
- no hidden scheduler,
- no direct posting,
- Travis approval required for publishing.

## Next Safe Lane

Create a local-only proof packet:

1. choose adult animated proof or fallback faceless mechanism proof,
2. inventory local tool availability,
3. produce or locate required assets,
4. build 10-15 second proof locally,
5. write evidence packet and scale/no-scale decision.

Do not publish, schedule, or create an automated long-form queue.

## Morning Definition Of Done

A good outcome is:

- one proof path selected,
- exact asset/tool requirements known,
- pass/fail criteria documented,
- no full episode attempted prematurely,
- no live platform action performed.
